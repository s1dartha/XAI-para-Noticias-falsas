# XAI para Detección y Análisis de Noticias Falsas

Proyecto de investigación y desarrollo enfocado en la clasificación y explicabilidad de noticias falsas (*Fake News Detection*) utilizando técnicas de **Inteligencia Artificial Explicable (XAI)** como SHAP, LIME y análisis de atención en modelos Transformer / NLP.

## 📁 Estructura del Proyecto

```text
XAI-para-Noticias-falsas/
├── data/
│   ├── raw/             # Datos originales sin procesar
│   └── processed/       # Conjuntos de datos limpios y preprocesados
├── models/              # Modelos entrenados y checkpoints
├── notebooks/           # Cuadernos Jupyter para experimentación y XAI
├── src/                 # Código fuente modular (pipelines, modelos, explicabilidad)
├── .gitignore
├── README.md
└── requirements.txt
```

## 🚀 Tecnologías y Herramientas

- **Python 3.12+**
- **NLP / Modelos**: Transformers, Hugging Face, Scikit-learn
- **XAI (Explicabilidad)**: SHAP, LIME
- **Análisis de Datos**: Pandas, NumPy, Matplotlib, Seaborn
